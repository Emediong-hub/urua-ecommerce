# URUA – E-Commerce Platform

## Project Overview

URUA is a full-stack e-commerce platform designed to provide users with a simple and convenient way to browse, purchase, and manage products online.

## Project Goal

The goal of URUA is to provide a reliable online marketplace where customers can discover products, add items to their cart, place orders, and manage their purchases.

## Core Features

* User registration and login
* Product browsing and search
* Product categories
* Shopping cart
* Order placement and management
* User profile
* Product management
* Admin dashboard

## Technologies

### Frontend

### Backend

* Java
* Spring Boot

* MongoDB
